# FitMe – Backlog / Improvements

## Notes per exercise (in-session)

**Текущее поведение:** одна заметка на всю сессию, сохраняется через `finishWorkout(session.id, note)`.

**Желаемое:** заметка привязана к конкретному упражнению внутри сессии.

**Что нужно:**

Backend:
- Добавить поле `notes: String?` в модель `WorkoutSet` (Prisma migration)
- Принимать `notes?: string` в `CreateSetInput` DTO
- Сохранять при `POST /workouts/:id/sets`

Frontend (`SetLogger.tsx`):
- Хранить `note` в `Map<exerciseId, string>` вместо одной строки
- При `logSets` передавать `notes` в первый сет группы упражнения
- `NoteModal` получает/сохраняет заметку по текущему `exerciseId`
- В `WorkoutHistoryCard` — показывать заметку под каждой группой упражнений, а не на уровне сессии

## Группировка истории тренировок по дате

**Текущее поведение:** карточки `WorkoutHistoryCard` рендерятся плоским списком.

**Желаемое:** карточки визуально сгруппированы под датой (как в Apple Health).

```
Пятница, 9 мая
  ┌─ Силовая · 45m ─┐
  └─────────────────┘
  ┌─ Кардио · 20m ──┐
  └─────────────────┘

Среда, 7 мая
  ┌─ Силовая · 60m ─┐
  └─────────────────┘
```

**Важно:** это чисто визуальный слой — логика start/finish/log не затрагивается.
Каждая сессия остаётся отдельной сущностью со своим `id`.

**Что нужно** (только фронт):
- В `workouts/page.tsx` сгруппировать `history` по дате `startedAt` (`format(date, "yyyy-MM-dd")`)
- Рендерить заголовок-дату перед каждой группой карточек
